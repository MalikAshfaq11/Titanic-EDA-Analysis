# Titanic Dataset - Exploratory Data Analysis

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) and Data Visualization using the Titanic Dataset.

## Analysis Performed
- Data Cleaning
- Handling Missing Values
- Duplicate Checking
- Feature Relationships
- Outlier Detection
- Data Visualization

## Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Insights
- Female passengers had higher survival rates
- First class passengers showed better survival probability
- Fare and passenger class influenced survival
- Several outliers existed in ticket fares
